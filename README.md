# 💍 Site de Casamento — Mariana & Gabriel

Este projeto é um **site de casamento desenvolvido especialmente para os noivos Mariana e Gabriel**, com o objetivo de criar um convite digital personalizado e apresentar aos convidados as principais informações sobre o casamento.

O site foi desenvolvido levando em consideração as preferências e escolhas dos próprios noivos, tornando o projeto único e personalizado para o momento especial do casal.

## 💐 Personalização

Durante o desenvolvimento do projeto, **Mariana e Gabriel participaram das decisões relacionadas ao visual e ao conteúdo do site**.

As escolhas dos noivos incluem:

* 🎨 Cores utilizadas no site;
* 🖼️ Imagens e elementos visuais;
* 📑 Seções presentes na página;
* 💍 Estilo e identidade visual do casamento;
* 📝 Conteúdos e informações apresentados aos convidados.

Dessa forma, o site foi desenvolvido não apenas como um projeto web, mas como uma representação das preferências dos noivos para o casamento.

## 📅 Informações do casamento

O site apresenta o nome dos noivos:

**Mariana & Gabriel**

E a data do casamento:

**13/03/2027**

Também conta com a frase escolhida para representar o casal:
